# Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience
for everyone, regardless of identity, background, experience, or viewpoint.

## Expected behavior

- Be respectful, constructive, and welcoming.
- Focus criticism on ideas and code, not people.
- Accept responsibility, apologize, and learn from mistakes.
- Respect privacy and never publish another person's secrets or private data.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, sexualized attention, sustained
disruption, and other conduct that a reasonable person would consider
inappropriate are not tolerated in project spaces.

## Enforcement

Project maintainers may remove, edit, or reject contributions and ban
participants whose behavior violates this code. Report conduct concerns
privately through the repository's GitHub security reporting channel.
